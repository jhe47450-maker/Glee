# ⚡ Quick Setup Guide

## 🚀 Deploy Backend on Replit (5 min)

1. Go to **replit.com**
2. Click **"+ Create"**
3. Select **"Import from GitHub"**
4. Paste: `https://github.com/jhe47450-maker/Glee`
5. Click **"Run"**

You get: `https://Glee-YOUR-USERNAME.replit.dev/api`

## 🎯 Deploy Frontend on GitHub Pages (3 min)

1. Go to **GitHub → Settings → Pages**
2. Source: `Deploy from a branch`
3. Branch: `main`
4. Click **Save**
5. Wait 2 minutes

You get: `https://USERNAME.github.io/Glee`

## 🔗 Connect APIs

Edit: `scripts/config.js`

```javascript
API_BASE: 'https://Glee-YOUR-USERNAME.replit.dev/api'
```
